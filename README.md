# WebStudio: Page Layout

A multi-section WebStudio landing page created during the GoIT HTML/CSS course.

## About the project

This stage develops the WebStudio page into a more structured layout. The markup uses reusable containers to align content and keep the header, hero, feature list, team, portfolio, and footer consistent.

## Highlights

- Shared content containers
- Structured header and navigation
- Multi-column content sections
- Separate CSS files organized by page section
- Consistent typography and spacing

## Technologies

- HTML5
- CSS3
- Flexbox-based layout
- Modern Normalize
- Google Fonts

## Run locally

Clone the repository and open `index.html` in a browser. No build tools are required.

## Learning focus

Building page layouts with CSS, grouping content into reusable containers, and organizing styles into smaller files.
